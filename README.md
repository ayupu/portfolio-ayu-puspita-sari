# Portofolio Ayu Puspita Sari

Website portofolio sederhana menggunakan HTML, CSS, dan JavaScript.

## Cara menggunakan
1. Unggah semua file di folder ini ke repository GitHub.
2. Pastikan `index.html` berada di root repository.
3. Aktifkan GitHub Pages melalui Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

## Bagian yang perlu disesuaikan
- `index.html`: ubah profesi, biodata, keahlian, proyek, dan email.
- `style.css`: ubah warna dan tampilan.
- Bagian foto: ganti elemen `.portrait-placeholder` di `index.html` dengan tag gambar foto Anda.

Catatan: teks dalam tanda kurung siku seperti `[Keahlian 1]` adalah contoh yang perlu diganti dengan informasi milik Anda.
